## 阶段 4：独立审查后的聚焦修正

- 独立审查先发现真实 PostgreSQL 查询错误：SEC `form=None` nullable bind 类型歧义；材料查询 `ESCAPE` SQL 字符串非法；V2 概率 JSONB `null` 参与 `COALESCE` 后遮蔽 baseline。修正为无 form 时省略条件、材料查询使用 PostgreSQL `E'\\'` 单字符转义、Python 选择首个非空 JSONB 概率字段；V2 无行返回真实空集，异常不再回退 legacy。加入 monkeypatch targeted tests。此运行环境不能访问隔离 DB，实际 PG RED→GREEN 由 parent acceptance suite 验证，不能宣称本 worker 已验证。
- 协议修正：转发 decision reasoning fields 到最终请求并完整存储受限 metadata；拒绝 malformed/missing/duplicate/oversized tool-call IDs、超限调用数组与超限 reasoning，不静默截断字段；至多两项请求、实际至多一个业务工具；工具请求先存，再执行。最终 reasoning delta 仅服务端保存，不进 SSE/restore。保留 4000 字符与 16KB UTF-8 answer 限制，历史 DB 读取限制 500 条并按完整 turn 与 UTF-8 JSON 字节预算裁剪；工具输出限 8KB。
- Provider SSE 决策与最终请求共用 25 秒总超时及 redirect 拒绝；400/404/422 维持友好 unavailable/invalid-request 错误。final SSE 受限字节行缓存、拒绝坏 JSON/结构、工具 delta、`length`/`tool_calls` 终止，并要求 `finish_reason=stop` 后收到 `[DONE]`。补充 mock transport 测试覆盖 redirect、422、reasoning、终止原因、坏 JSON 和 EOF。
- 生命周期修正：REQUEST_SLOTS 覆盖完整 turn； acquire 取消、async generator 退出与 response background cleanup 均释放资源，lock registry 随请求结束清理。锁只保障单进程，不宣称分布式 HA。assistant tool-request 在 I/O 前持久化，取消/失败记录终态。
- 前端修正：EOF 不含 `done` 视为失败；部分回答保留并显示失败/取消；工具结果按 call_id 恢复/匹配；取消、设置变化把运行中状态标停；restore 在 lifecycle 校验后改状态，陈旧流不能更新 sessionStorage conversation 指针。移动端 trace `<pre>` 已有 `pre-wrap`、`overflow-wrap:anywhere` 和 220px 高度上限。导航标题改为研究工具。没有增加 API key 持久化。
- Demo 修正：只允许 DB 名以 `test_agent_chat_demo` 开头；通过 SQLAlchemy metadata 创建模型表、ORM 显式填写 `content_truncated=False` 并幂等插入，删除重复手工 DDL。API 默认 8018、mock 默认 8899、可配置；README 有 disposable DB 创建说明及前端 `VITE_API_BASE_URL` 命令。新增 `scripts/evaluate_agent_chat_demo.py` 运行 fixture endpoint cases，校验五日 AAPL 日期/价格、SEC 日期/来源、FAQ 命中/字面 miss、AMD 空结果；回答显式 `DEMO MOCK` 并展示来源/as-of。
