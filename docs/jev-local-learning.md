# Jev 本地概率校准与反馈闭环

更新：2026-09-28

## 目标与边界

本地模型不会训练或修改 OpenRouter 上的 Jev，也不会把 DeepSeek 的简报当作 Jev 的“内部思维”。它学习的是：在同一 Jev 模型、问题版本和 20 交易日目标合同下，Jev 给出的看跌 / 中性 / 看涨分布与已到期真实标签之间，是否存在可重复的校准偏差。

校准器是一个正则化的多分类逻辑回归，输入为 Jev 三类概率的中心化对数概率，输出仍是三类概率。材料全文、分析文字、预测结果和未来行情都不会进入这组校准特征。训练不调用外部模型，不产生 API 费用。

## 每次预测的闭环

1. 预测版本仍不可变地保存实际用于展示和评分的 `decision_probabilities`。
2. Jev 原始三类概率保存在版本的 `model_manifest.decision_provider.raw_probabilities`。如果调用时没有合格的本地模型，原始概率就是最终概率，并记录回退原因。
3. 目标满 20 个 XNYS 交易日后，现有 point-in-time evaluator 安全刷新目标收盘价、核验公司行动并追加评分结果。
4. 每小时 SEC monitor 完成独立评估后，自动运行 Jev 学习周期。训练只读取已持久化的成熟结果。
5. 实时学习数据按 OpenRouter 实际模型、问题版本和固定目标合同分组。只纳入 `observed` 根预测；预测修订不另算样本。`historical_research` 回放不进入实时校准器。
6. 候选模型按月份切分：早期月份训练，最近 30% 月份留作时间外验证。至少需要 420 个已成熟根、18 个验证月份、训练集每类至少 20 条、验证集每类至少 8 条。
7. 候选必须在月份分块 bootstrap 的 95% 区间下，Brier 分数同时优于训练期类别比例基线和原始 Jev；Log loss 相对两者都不得恶化超过 0.01。已有线上校准器时，新候选还必须在相同验证期优于它。否则候选被拒绝，保留旧模型或继续使用 Jev 原始概率。
8. 生效模型系数与训练清单写入 `jev_calibration_models_v2`。模型参数按 SHA-256 核验。每次新预测只在精确 cohort 匹配且完整性核验通过后使用；历史回放明确不套用未来校准器。

## 界面和 API

- 预测工作台标明当前显示的是 Jev 原始值还是“Jev + 本地校准”，并可展开查看校准前的原始概率。
- “到期评估”页面展示观察样本、成熟样本、待到期样本、历史回放排除数，以及当前校准器的时间外分数。
- `GET /v2/jev-learning/status?symbol=AAPL` 为只读状态接口。训练只在每小时 monitor 的评估周期后发生。

## 十年历史回放研究集

历史回放可以单独用来研究 Jev 的概率校准，但不冒充当年实时预测，也不自动影响实时输出。历史调用发生在当前时间，Jev 可能已经从模型训练数据中见过后来发生的事件；因此，即使只输入决策日之前公开的 SEC 材料和 K 线，这些结果仍有模型知识前视风险。

- `scripts/backfill_jev_replay_prices.py --apply` 将七只股票和 SPY 的日线补到十年窗口，并保留标记为 `historical_research` 所需的初始回填版本。
- `scripts/enqueue_jev_history_batch.py --from-month 2016-09 --through-month 2026-07 --apply` 按每月最后一个已成熟交易日，为七只股票创建回放任务。只选择决策日之前已公开、且市场特征完整的日期；每个预测仍使用 20 个 XNYS 交易日的原目标。
- SEC 材料按准确的 SEC 接收时间截断。材料现在才抓取这一事实仍保存为真实 `observed_at`；这类回放明确标记为历史研究，不表示系统当时已经取得材料。
- 预测任务完成后，原评估器会追加成熟目标标签。`scripts.watch_and_train_jev_history.py` 等待整批任务结束，再运行 `scripts.train_jev_historical_research.py`，输出 `artifacts/jev-historical-calibration.json`。
- 离线候选只用原始 Jev 三类概率训练正则化逻辑回归，并按日历月份做时间外验证。报告包括样本数量、类别比例、Brier / Log loss 和训练清单；无论历史验证结果如何，该候选都不会写入实时模型表或用于实时预测。只有未来独立的 `observed` 样本验证通过后，才考虑接入线上。
- 目标区间跨拆股、缺少材料分析或材料引用校验失败时，预测概率或成熟标签可能缺失；训练器只收纳有有效 Jev 概率并有成功到期标签的根预测，不复制或补造样本。

## 当前验收基线

实时校准器仍只读取 `observed` 样本；2026-09-28 启动的十年历史批次是独立研究集，不能增加实时学习状态中的成熟样本数。当前开发库有 4 个 `observed` 根预测，均未到期；实时校准器尚未训练或启用。历史批次生成多少有效预测和研究模型，取决于各份材料分析、引用校验、模型调用和到期价格评估是否成功。

项目另有历史行情模型实验，但封存测试中的 Brier 与 Log loss 均差于简单类别先验，所以该市场模型没有接入线上概率。十年 SEC 财报库存本身不等于十年 Jev 训练样本：每个历史点都必须实际生成 Jev 输出，再等待对应 K 线到期，才能形成监督标签。

## 运行与恢复

- 先通过 `python -m scripts.migrate_forecast_v2 --check` 查看 schema，再用 `--apply` 添加学习模型表；迁移仅创建缺失的 V2 表，不清理业务数据。
- 重新启动 API 和 SEC monitor 后，新预测会保存原始 Jev 概率；monitor 后续会自动评分并尝试训练。
- 若 monitor 暂停，系统仍可创建预测，但评估和学习不会自动前进；`GET /v2/monitor/status` 与 `GET /v2/jev-learning/status` 分别用于检查服务扫描和样本状态。
- 候选和当前模型都以追加式行保存。数据新增或安全价格修订后，数据集指纹变化才触发新的候选训练；同一批样本不会反复训练。
