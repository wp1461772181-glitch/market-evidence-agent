# 已保存 AI 分析接入知识库

用户授权：“那你先把我刚刚说的分析结果入库做了吧”。这是现有资料入库链路的增量；上一轮讨论已确定复用 PostgreSQL 的分析结果、保留原文依据、版本和权限。直接执行，不重新询问确认。

## 目标与范围

- 将 `material_analysis_versions` 的摘要、事实提取、支持/反对推论、关键数字、不确定项转换为可检索的知识文档。
- PostgreSQL 仍为权威源；复用现有 BGE-M3、Milvus、幂等任务与单片段后台索引。无新模型、数据库或付费分析调用。
- 新来源类型 `ai_analysis`，明显标注“已保存 AI 分析，非官方原文”；不混入现有原文工具 `query_materials`。增加 `search_material_analysis(symbol, keyword, limit=5)` 语义检索工具，沿用知识工具执行预算、引用与充分性检查。
- 知识库后台增加“已保存 AI 分析”导入来源和分析检索测试类型，沿用现有布局；版本、原始来源与引文可查看。
- 不扩展 Agent Loop、意图识别、指代消解，不把本次功能宣称为修复先前供应商流式或 sufficiency 异常。

## 数据与安全契约

- 按源材料分组，当前入库只选择最新分析版本（created_at/version_no/id 确定性排序）；不能按随机 UUID 顺序反复把旧分析激活。人工选择旧分析也不得替代当前版本。新版本使旧知识文档 superseded，保留旧文档/向量。
- 文档逻辑 source_id 包含原始材料类型和 ID；source_version 为分析 UUID。标题含 AI 分析标签、股票、材料标题和版本；章节按摘要、事实、推论、数字、不确定项组织，保留条目原文引文和事实依赖。
- 入库前校验冻结输入 hash、来源清单与材料关联、当前源正文 hash/来源状态、结构及精确引文；数字仍保存结构化原表，不声称抽取结果已获人工认证。分析 payload/引用/模型/版本等参与稳定 source_hash。
- 公共 SEC 分析可公开检索；上传材料分析必须存在 owner mapping，并继承其 private owner。未知归属绝不公开，包括站点所有者的语义检索。导入、检索、引用读取与历史恢复均验证权限和当前源一致性。
- 分析 available_at 不早于原材料和分析生成时间；未来分析、错误股票、源变更、payload 变更、owner 变更、撤回或失效引用不能通过检索/引用。
- 新引用详情标记 derived AI analysis，并显示分析版本/模型、原文引文和真实来源链接。原文引用与分析引用不能互换。

## 同步与交付

- 增加 `analysis` 有界持久 keyset 同步，循环可发现新分析；每轮只选最新有效分析。仅排队后沿用后台单块模型调度，不批量占用推理。
- CLI 支持显式分析 ID 及有界分析页同步，报告接受/跳过；不删除/重新分析现有数据。现有合法 AMD 分析先完成真实索引验证，其余自动回填并明确未完成数量。
- 功能验收：幂等、新旧版本、private/未知 owner、当前 hash/payload 变更、时间与股票、原文/分析隔离、引用/历史恢复；真实本地 BGE/Milvus 的 AMD 分析语义检索及 citation readback。先无需新的付费 LLM 调用。
- 沿用既有 GitHub/线上发布授权：只提交本次精确路径，从干净归档验证，保留旧 release/数据库/集合/用户学习修改。最终报告实际在线验证和剩余回填边界。
