# V2 纯行情基线：首次固定评估

评估日期：2026-09-25。范围仅为 `provider_quote_close_v1` 的股票绝对价格收益三分类，固定目标为根日后第 20 个 XNYS 交易日收盘，±2%（含边界）为中性。**这里没有把财报或媒体输入数值模型。**

## 数据与执行

- 输入：五只股票与 SPY 的六份哈希验证价格快照；每份 1,421 个交易会话，均为 2026-09-25 前后获取的 `historical_research` 回填材料。公开清单摘要见 [V2 数据集清单](v2-dataset-manifest-summary.json)，原始文件保存在被 Git 忽略的 `data/v2/`。
- 训练根行 3,305；独立校准根行 1,140；封存测试根行 1,980。历史不足 300、跨分区 300、跨拆股 80 被排除。每条根行只用其 anchor 当日或更早的六个行情特征，另加固定 `remaining_sessions=20` 与 `realized_return_from_anchor=0`。
- 固定一次训练流程：训练集拟合中位数填补、标准化和 `LogisticRegression(C=1, random_state=42)`；校准集单独做 sigmoid 校准；完成后才对封存测试集评估一次。对照为训练集类别先验。没有根据这次测试结果搜索参数、重划分或重训。
- 本地不可覆盖产物：`artifacts/v2/market-20260925-market-baseline-01/`，状态 `research_only`，`joint_probabilities=null`。模型 SHA-256：`8d78143290b4b0f09714385516a1b8d88f2aa72eaae33a8833f97c4efa839779`；数据清单 SHA-256：`93132970c68ad51c2d4d86b787e2cca6ac45fb1e811698418daf57e011d31379`；训练行 SHA-256：`681b3ab6e64f754c8c34d771a4b87513e9dea433662a74f6610c7b6a4ae4b62c`。重新加载核验模型文件哈希与清单、训练行哈希一致，单条回放三类概率之和为 1。

## 仍需完成

- P3 现在可以从同一份冻结行情快照为每个合格根构造 19 条候选修订行：修订行保留根基准价、固定目标日和最终标签，使用修订当日可见的行情特征、`remaining_sessions` 与根至修订日的已实现收益。它们稳定携带 `root_id`，且与根锁在同一日期分区。该构造只在显式要求修订候选行时启用，不能进入本次 root-only artifact，也不能把同根行按独立样本重复计数。
- 仍没有足够的真实历史“新材料到达后触发修订”样本，盘后公告时点和价格更正回放也尚未构造。因此候选行只验证了固定目标和无未来行情特征的 fixture 能力，不构成修订或证据增益的真实效果评估；本次封存测试没有为此重训或重复查看。
- P4 证据通道需要足量官方与媒体事件、双端可核对财务事实及独立封存验证；目前两份官方试点和零份真实手动媒体不足以训练联合模型，不能产生联合概率。
- 历史回填不等于当年实际观测或真实前向预测。相邻根的 20 日目标区间大量重叠，本表未给出独立根/事件重采样区间，不能将 1,980 行当成 1,980 个完全独立市场事件。
