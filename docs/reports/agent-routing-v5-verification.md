# V5: progress-aware execution and targeted validation

本报告覆盖用户于2026-10-16批准的后续修订。V4报告中的“不得修改数字/事件守卫、批量执行语义”是当时的范围限制，已由本轮批准的计划替代。历史测试和原生模型结果保留，不当作本版本验收。

## 已实现 / Implemented

- **长任务按真实进展继续**：移除Agent累计token、固定总时长和固定总步骤上限，保留用量统计。原生决策改用流式协议；内容、推理和函数参数增量续期请求本地的空闲计时，空心跳/仅role帧不续期。保留连接/读空闲超时、有限重试、取消、单次响应和模型上下文容量。最近完整工具协议批次压缩进入上下文，不留下孤立tool消息。重复工具调用/重复证据仍停止。
- **逐段回答校验**：缺失/错误引用、未支持的数字或事件只影响相关段落；保留有效内容并尝试一次工具禁用的结构化修复。修复失败不替换已有有效内容。普通裸数字也核对。股价引用无需每句包含股票词。安全的操作完成提示由实际服务器状态重建，不豁免模型任意文字。
- **可复核计算**：`calculate`只接受本轮已核验来源中的数值，使用受限AST及Decimal执行四则运算，记录输入、公式、父来源和结果。计算来源标为derived，不伪装成官方原文。拒绝未知来源/不存在的输入、函数调用、属性访问、幂运算、除零及超界表达式。
- **代指与范围**：提供服务器生成的消息和清单项ID，由服务器恢复条目原文；拒绝伪造ID和选错序号。兼容短原文引用，并给一次纠正机会。精确官方发行人名称优先于前缀匹配；双语已接地提及、验证过的更早公司切换和服务器时间推导的相对日期不再无故弹卡。仅时间/数量细化恢复原任务字段；明确任务切换由结构化语义标志表达。
- **SEC与写入**：拉取前可只读发现最新官方目录元数据，无需手动先扫描；登记目录和下载原文仍在冻结确认后执行。agent主动建议在第一次批准前不发现/下载，批准后发现目标并生成第二张精确确认卡，重放不重复发现。缺少部分目标时显示实际/请求数量，错误序号、越界、多提目标和跨会话来源仍拒绝。条件入库使用类型字段与真实日期比较，确认执行再次检查冻结日期条件。
- **批量独立执行**：独立目标逐项记录成功或安全错误后继续。每项副作用前提交executing journal，保留父能力锁和幂等键；崩溃留下未知执行状态，不能自动重放。权限失效、执行中取消或取消Agent等待停止后续项，依赖失败跳过依赖项；已开始的副作用不假装撤回，已完成项保留。
- **网络与帮助**：移除敏感词整句拒绝，允许模型设置/API Key填写帮助；不增加读取私钥或删除数据库工具，运行时key继续脱敏。公网抓取保持HTTPS、DNS/IP固定、私网拒绝、类型/跳转/体积边界。显式配置的本地模型走独立的精确地址/模型路由限制，不能用于访问任意内网URL。

## 运行配置 / Operator configuration

默认正常任务没有累计token/总运行秒数/总步骤限制。单次模型输出上限和响应体边界是资源保护，不能当作累计任务预算。不可见的模型内部运算无法证明进展；长时间没有可见内容/推理/函数参数时仍按空闲处理，单纯连接存活不能无限续期。

本地OpenAI兼容模型仅由运行后端的运维者配置，例如：

```sh
AGENT_LOCAL_MODEL_BASE_URLS='["http://127.0.0.1:11434/v1"]'
```

浏览器填写同一Base URL和实际模型名。现有表单仍要求至少8字符API Key；无鉴权的本地服务可使用无保密意义的占位值。`127.0.0.1`指**后端所在主机**；浏览器在另一台机器不会改变这一点。仅允许GET `/models`与POST `/chat/completions`；私网/回环地址必须精确匹配配置，DNS混入公网、链路本地/元数据地址、额外路径和query均拒绝。不要将内部管理服务加入该配置。

网页体积可用`AGENT_WEB_PAGE_MAX_BYTES`与`AGENT_WEB_SEARCH_MAX_BYTES`调整，默认2MB/512KB，允许范围32KB–10MB；正文摘录、内容类型及跳转限制仍保留。公网网页绝不使用本地模型通道。
